## My portfolio site

[**joseparhusip.com**](https://www.joseparhusip.com) · [source code](https://github.com/joseparhusip/jose-elio-parhusipp)

- **Bilingual:** Indonesian and English, including the chat assistant and the confirmation emails.
- **3D ID card:** a lanyard card built with Three.js and custom rope physics. Drag it to swing it, tap it to flip it.
- **Chat assistant:** a rule-based assistant (no AI) that answers questions about me and forwards messages to my inbox.
- **Privacy first:** no cookies, ads, or trackers.
- **Fast:** WebP images, self-hosted fonts, and lazy loading for the chat, the map, and the 3D card.
- **Secure:** a strict Content Security Policy, HSTS, and a hardened contact form API.
- **Built with:** Vue 3, Vite, Three.js, Leaflet, and a Vercel serverless function with Nodemailer.
